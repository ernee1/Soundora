# Soundora (Aşama 1)

Derleme: Android Studio (Koala+) ile klasörü aç -> Sync -> Run (gerçek cihaz önerilir).
APK: Build > Build APK(s).

Çalışması hedeflenen: 16 adımlı Beat Maker (7 davul, BPM, hazır kalıplar, kanal sesi),
5 enstrüman + 2 oktav klavye, mikrofon kaydı (WAV, dalga formu, çal/yeniden adlandır/sil).

HENÜZ YOK: çok kanallı stüdyo, efektler, proje kaydetme, MP3/WAV dışa aktarma, şablonlar,
öğrenme bölümü, açık tema, arka plan servisi, içe aktarma.
